#  Oddish — Alimentação Saudável

##  Sobre o projeto

O **Oddish** é um sistema desenvolvido como projeto de TCC com o objetivo de auxiliar pessoas com restrições alimentares na escolha de alimentos adequados.

A aplicação permite consultar alimentos e encontrar sugestões de substituições, facilitando a busca por opções que atendam às necessidades alimentares de cada usuário.

##  Objetivo

Desenvolver uma solução tecnológica que facilite o acesso a informações sobre alimentos e ajude pessoas com restrições alimentares a encontrar alternativas para determinados alimentos.
